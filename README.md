# Пул вопросов с собеседований QA

Тренажёр для подготовки к собеседованиям QA: вопросы с реальных собесов, частота (на скольких собесах встретился вопрос) и эталонные ответы.

**Сайт:** https://krutykhanna.github.io/qa-interview-questions/

## Что умеет

- **Все вопросы.** Ответы скрыты, открываются по клику. Есть поиск, фильтры по разделу, типу, частоте и своему статусу, сортировка «самые частые сверху».
- **Тренировка.** Карточки: вопрос → ответь вслух → «Показать ответ» → «Знаю» или «Повторить». Можно выбрать раздел, только непройденные или только «повторить». Клавиши: `Пробел`, `←`, `→`.
- Отметки «знаю / повторить» хранятся в браузере студента (localStorage), регистрации нет.
- У каждого вопроса есть ссылка (`#q042`), её можно отправить ученику.

## Как устроено

```
index.html               страница
assets/style.css         стили (светлая и тёмная тема, мобильная вёрстка)
assets/app.js            логика: фильтры, тренировка, прогресс
data/questions.json      все вопросы и ответы — единственный источник для сайта
tools/build_questions.py сборка questions.json из Markdown-выгрузки документа
```

Формат вопроса в `questions.json`:

```json
{
  "id": "q042",
  "section": "s03",
  "type": "theory | practice | situational | personal | company",
  "question": "Что такое идемпотентность?",
  "frequency": 5,
  "answer": "ответ в Markdown",
  "answer_html": "тот же ответ в HTML"
}
```

## Как обновляется

1. Вопросы и ответы редактируются в документе «Пул вопросов с собеседований QA».
2. Документ выгружается в Markdown, затем `python3 tools/build_questions.py pool.md` пересобирает `data/questions.json`. id существующих вопросов сохраняются, поэтому отметки студентов не сбрасываются.
3. После коммита в `main` GitHub Pages обновляет сайт примерно за минуту.
